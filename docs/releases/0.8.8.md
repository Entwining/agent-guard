# v0.8.8

A project's `.cargo` directory is no longer refused as a credential directory, so searching, diffing or copying it, such as `rg PATTERN src .cargo`, `git diff -- .cargo` or `cat .cargo/*`, is permitted. Cargo reads a project's `.cargo` only for configuration and keeps credentials in its home, so only `~/.cargo` is refused as a whole, now including the directory it links to when it is a symbolic link. Cargo's credentials files stay protected in any directory named `.cargo`: `cat .cargo/credentials.toml` and `cat .cargo/*.toml` are still denied.

The guard does not read `CARGO_HOME`. A Cargo home that `CARGO_HOME` places outside `~/.cargo` is no longer refused as a whole when its directory is named `.cargo`, and was not protected under any other name; add it to the consumer's read restrictions, as the [known limits](https://github.com/Entwining/agent-guard/blob/v0.8.8/docs/setup.md#what-a-command-does-when-it-runs) describe.
