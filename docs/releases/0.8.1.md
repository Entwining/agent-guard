# v0.8.1

The guard's checks are unchanged from v0.8.0. This release changes how the package builds from source.

`make build` now renders the third-party license notices into the package as `LICENSE-THIRD-PARTY.md`, which needs cargo-about 0.9.2. It also requires `CARGO_TARGET_DIR`, set to an absolute directory outside every Git checkout, instead of placing the Cargo target next to `OUT`. Building from source needs Rust 1.99.0 or later.

Homebrew installations need no action.
