# v0.6.0

Install or upgrade with `brew install loophubs/tap/agent-guard` or `brew upgrade loophubs/tap/agent-guard`. Homebrew builds the release from tagged GitHub source. The installed hook no longer requires Node.js or Bun.

The legacy `@loophubs/agent-guard` npm package is retired and will receive no further releases. Existing npm or Bun global users must install the Homebrew package and [update registered hook paths to `/opt/homebrew/bin/agent-guard`](https://github.com/LoopHubs/agent-guard/blob/v0.6.0/docs/setup.md#install) before removing the old global package.

Bash bracket globs that combine POSIX character classes with literals are checked conservatively against protected App Data and credential paths. Glued tar `-C` options retain the entire directory value when it contains an uppercase `C`. Both fixes deny some commands that v0.5.0 allowed.
